# 自动更新与应用图标验证记录

日期：2026-11-06。此记录区分已执行验证与尚未完成的整体验收，不代表正式发布批准。

## 已执行

- Windows .NET Framework 4.8 Release 构建通过。
- Cloudflare 两套 TypeScript 类型检查通过，两个更新发布脚本语法检查通过。
- NSIS 3.12 编译包含品牌图标的安装包通过；安装包 678989 字节，产品版本 1.0.0。
- 产品版本配置为 1.0.0，程序集文件版本为 1.0.0.0，产品版本为 1.0.0；安装包版本一致。
- ICO 包含 16、20、24、32、40、48、64、128、256 像素九种尺寸；从实际 EXE、安装包提取的图标均为新品牌图标。
- 数字版本比较验证 1.9.0 小于 1.10.0，拒绝缺段、前导零、预发行和超范围格式。
- 临时 RSA 密钥签名的有效版本信息通过，错误签名、其他产品、跨源地址、错误协议、大小和版本字段被拒绝。
- 实际 Worker 路由代码配合模拟资产验证：支付配置缺失时 GET/HEAD 更新可用，POST 返回 405、缺失资产返回 503、HTTP 被拒绝，latest 不缓存、版本化包使用 immutable 缓存。
- 实际 .NET Framework 更新客户端通过内存 HTTP handler 验证：合并并发检查、识别新版、相同或较旧版本不升级、完成后不产生额外请求、正确下载进度达到 100% 并就绪、错误摘要被拒绝、失败后重试成功。
- 同一内存验证确认：正文停传后取消下载可结束等待并重新下载；停传版本信息约 10 秒超时（验证上限 13 秒）；302 被拒绝；缺少更新配置安全失败。该验证没有连接真实 HTTPS 更新源。
- 实际桌面检查确认主窗口正常运行，Settings → Software updates 可打开；未配置更新源时明确显示检查失败，主窗口保持运行。
