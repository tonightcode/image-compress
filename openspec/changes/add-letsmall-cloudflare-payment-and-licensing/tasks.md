## 验收用例清单

以下是待执行用例及预期结果，不代表已经通过。

| 输入或操作 | 预期结果 |
| --- | --- |
| 支付配置缺失时点击购买 | 不发起实际付款，提示尚未开放 |
| 正确商品、USD 单价 690 美分、数量一且通知有效 | 对应会话订单确认付款 |
| 单价正确但总额包含合法税费 | 不因总额高于 690 美分而拒绝 |
| 伪造签名或过期通知 | 不确认付款、不产生可领取授权 |
| 重复付款事件或重复交易 | 不产生第二份授权、不重置绑定 |
| 浏览器仅提交交易号或 success 参数 | 不解锁、不泄露激活凭证 |
| 正确会话在付款通知之前查询 | 显示等待确认 |
| 已付款、有效凭证和合法设备首次激活 | 返回可被 C# 验签的本机许可证 |
| 两台设备并发领取 | 只有一台成功 |
| 领取后再次提交同一凭证 | 拒绝 |
| 领取凭证超过十分钟期限 | 拒绝，不自动签发新凭证 |
| 本地许可证被清理后提交旧订单 | 不补发，保持免费模式 |
| 云端重新部署后再次领取旧订单 | 仍拒绝，保留原绑定 |
| 沙箱凭证提交生产接口 | 不解锁生产客户端 |
| 已激活软件离线重启 | 继续本地验签解锁，不请求云端检查 |
